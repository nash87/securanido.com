Platform

Plattform

Signed, reproducible, self-healing

Signiert, reproduzierbar, selbstheilend

Self-hosted Kubernetes with HA, automated recovery, and tested rollback. Every container image is cryptographically signed and ships with a verifiable SBOM — the cluster rejects anything missing either. Production runs the same artifacts that left local development.

Selbstgehostetes Kubernetes mit Hochverfügbarkeit, automatisierter Wiederherstellung und getesteten Rollbacks. Jedes Container-Image ist kryptografisch signiert und führt eine verifizierbare SBOM — fehlt eines, lehnt der Cluster es ab. In Produktion laufen exakt dieselben Artefakte, die das lokale Setup verlassen haben.

Multi-tenant from the database up

Multi-Tenant ab der Datenbankschicht

Customer separation enforced at the database layer, not retrofitted in application code. Cross-tenant data leaks aren't a bug class — they're structurally prevented. Roles, permissions, and audit logs are first-class at the trust boundary.

Mandantentrennung wird auf Datenbankebene durchgesetzt, nicht im Anwendungscode nachgerüstet. Cross-Tenant-Datenlecks sind so keine Bug-Kategorie, sondern strukturell ausgeschlossen. Rollen, Berechtigungen und Audit-Logs sind First-Class an der Vertrauensgrenze.

AI with identities and budgets

KI mit Identitäten und Budgets

Agents have verified identities, run inside controlled execution sandboxes, and leave a complete audit trail. Inputs pass a runtime validation gate — prompt-injection, PII leakage and loader-hijack are screened before a tool call runs. Multiple LLM providers with automatic failover. Token-cost budgets enforced before money is spent.

Agenten haben verifizierte Identitäten, laufen in kontrollierten Ausführungs-Sandboxes und hinterlassen einen lückenlosen Audit-Trail. Eingaben durchlaufen eine Laufzeit-Prüfung — Prompt-Injection, PII-Abfluss und Loader-Hijack werden erkannt, bevor ein Tool-Aufruf ausgeführt wird. Mehrere LLM-Anbieter mit automatischem Failover. Token-Kosten-Budgets greifen, bevor Geld ausgegeben wird.

Web, mobile, and tooling — same engineering bar

Web, Mobile und Tooling — derselbe Anspruch

User-facing applications built to the same standards as the platform beneath them: accessible by default, internationalized, GDPR-compliant out of the gate. The mobile side is a first-class platform target — not a thin wrapper around a website.

Endnutzer-Anwendungen entstehen nach denselben Standards wie die Plattform darunter: barrierefrei, mehrsprachig, DSGVO-konform ab Start. Die Mobile-Seite ist ein vollwertiges Plattform-Target — kein dünner Wrapper um eine Website.

One pattern, fifty services

Ein Muster, fünfzig Services

The platform is built from small Rust crates that follow one rule: each is both a fop subcommand locally and a signed Kubernetes microservice in the cluster — same code, two runtimes.

Die Plattform besteht aus kleinen Rust-Crates, die einer Regel folgen: Jedes ist sowohl ein lokaler fop-Subbefehl als auch ein signierter Kubernetes-Microservice im Cluster — derselbe Code, zwei Laufzeiten.
